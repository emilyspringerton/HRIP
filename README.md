# HRIP — Hearthstone Rip

Scoping only, 2026-10-09. No code yet.

HRIP will be a pure-PARENA, batteries-included Windows app that extracts Hearthstone's own card
data directly from a local game install, and emits JSON for upload into WOTAN's Hearthstone card
database. See [`NORTHSTAR.md`](NORTHSTAR.md) for the full scoping pass: the checked PARENA
capability audit, what's real vs. aspirational, the real gaps, the V0 cut, and the phased plan.

**Status: planning.** Nothing in this repo runs yet.
